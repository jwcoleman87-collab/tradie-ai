# Workbench brand implementation

**Status:** Approved product direction  
**Primary visual source:** `workbench-styleboard.png`

Workbench is the practical backend crew that helps trades businesses run the
work behind the work. Product language should emphasise the owner, their crew,
practical outcomes and owner control. Technology remains secondary.

## Core system

| Role             | Approved value |
| ---------------- | -------------- |
| Workbench yellow | `#F1B505`      |
| Workshop ink     | `#030D18`      |
| Steel navy       | `#152D47`      |
| Utility grey     | `#8E9195`      |
| Warm white       | `#EBEBEB`      |
| Display type     | Work Sans      |
| Body type        | Inter          |

The application uses the product model **Crew → Magic Chat → Workspace**.
Yellow is reserved for active states, important actions and signals. Dark navy
surfaces carry the shell and Crew navigation; work content stays light and
high-contrast.

## Logo assets

- `public/workbench/mark.png` — joined owner-and-crew mark.
- `public/workbench/lockup.png` — approved mark and Workbench wordmark.
- `public/og.png` — social preview for the current brand.

Use the supplied assets without redrawing, recolouring, stretching or adding
effects. Keep clear space around the mark and place it on quiet dark or light
surfaces with strong contrast.

## Product language

- Product: **Workbench**
- Central conversation: **Magic Chat**
- Assistant: **Magic**
- Specialists: **Your crew**
- Positioning: **Your business. Your crew. One place.**

Legacy infrastructure identifiers may still contain `tradie-ai` or `Tradie AI`
where changing them would break OAuth, deployment, database or cloud-service
configuration. They are implementation identifiers, not current product
branding.
